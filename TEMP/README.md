# TEMP / archiwum

Ten katalog zawiera materiały pomocnicze, referencyjne i historyczne, które nie są częścią działającej aplikacji.
Nie jest kopiowany do `server/public` ani używany podczas wdrożenia.

- `referencje-kyu-9/` — zdjęcia referencyjne do poziomu 9 Kyu.
- `bledy/` — zachowane materiały diagnostyczne (jeżeli były obecne).
- `legacy-docs/` — stare instrukcje wdrożeniowe i historyczny zapis wersji usługi.

Kod możliwy do odzyskania pozostaje również w historii Git; aktywnych plików aplikacji nie archiwizujemy tutaj.
